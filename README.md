# 🌐 Personal Portfolio Website

Мой личный сайт-визитка, созданный для демонстрации навыков, пет-проектов и контактов. Поддерживает адаптивную верстку под мобильные устройства и десктопы.

## 🔗 Ссылка на проект
👉 [Посмотреть сайт вживую](dokiriii.github.io/)

## 🛠️ Стек технологий
* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
* **Hosting**: GitHub Pages

## 📁 Структура проекта
* `index.html` — основная разметка страницы
* `/css` — стили и кастомная анимация
* `/JavaScript` — интерактивные элементы и логика
* `/images` — графические ассеты и скриншоты
